# برنامج الملاحظات

تطبيق ملاحظات عربي يعمل في المتصفح وعلى الهاتف (Android)، يدعم المجلدات، وتغيير الثيم، وأنماط الورق، والتحديد المتعدد، والمشاركة كصورة.

## هيكل المشروع
- `www/index.html`: التطبيق نفسه.
- `capacitor.config.json`: إعدادات تحويله إلى تطبيق Android.
- `package.json`: الحزم اللازمة.
- `.github/workflows/build-apk.yml`: سير عمل GitHub Actions الذي يبني ملف APK.

## الخطوات

### 1. رفع المشروع إلى GitHub
1. أنشئ مستودعاً جديداً في GitHub (مثلاً `notes-app`).
2. ارفع محتويات هذا المجلد إليه، ويجب أن يكون الفرع الرئيسي اسمه `main`.

```bash
git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/USERNAME/notes-app.git
git push -u origin main
```

### 2. بناء ملف APK تلقائياً
- بعد الرفع يبدأ سير العمل تلقائياً. يمكنك متابعته من تبويب **Actions** في المستودع.
- عند انتهائه، افتح تشغيل العمل (Run) واختر **notes-app-apk** من قسم **Artifacts** لتحميل ملف APK.
- يمكنك أيضاً تشغيله يدوياً من **Actions ← Build APK ← Run workflow**.

### 3. تثبيت التطبيق على الهاتف
1. انقل ملف `app-debug.apk` إلى الهاتف.
2. فعّل "تثبيت التطبيقات من مصادر غير معروفة" من إعدادات الهاتف.
3. افتح الملف واضغط تثبيت.

## ملاحظات
- الملاحظات تُحفظ داخل التطبيق على الهاتف، وتُحذف إذا حذفت بيانات التطبيق أو أزلته.
- ملف APK الناتج من نوع Debug، مناسب للتجربة والاستخدام الشخصي. لنشره في متجر Google Play تحتاج إلى نسخة Release موقّعة.
- زر المشاركة يعتمد على دعم الجهاز، وقد يحتاج تحسيناً لاحقاً باستخدام إضافة Capacitor Share.
